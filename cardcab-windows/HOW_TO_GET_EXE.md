# Как получить готовый EXE файл

## Способ 1: Через GitHub (рекомендуется)

### Шаг 1: Создайте репозиторий на GitHub
1. Зайдите на https://github.com и войдите в аккаунт (или создайте)
2. Нажмите "New repository" (зелёная кнопка)
3. Назовите репозиторий `cardcab`
4. Нажмите "Create repository"

### Шаг 2: Загрузите код
1. На странице нового репозитория нажмите "uploading an existing file"
2. Перетащите ВСЕ файлы из этого архива в окно браузера
3. Нажмите "Commit changes"

### Шаг 3: Дождитесь сборки
1. Перейдите во вкладку "Actions" в вашем репозитории
2. Вы увидите запущенный процесс "Build Windows Installer"
3. Подождите ~10-15 минут пока сборка завершится (зелёная галочка)

### Шаг 4: Скачайте готовый exe
1. Нажмите на завершённую сборку
2. Внизу страницы в разделе "Artifacts" скачайте:
   - **CardCab-Windows-Installer** — установщик (рекомендуется)
   - **CardCab-Windows-Portable** — портативная версия (без установки)

## После установки

### Запуск PostgreSQL (обязательно!)

Приложению нужна база данных PostgreSQL. Самый простой способ — через Docker:

1. Установите Docker Desktop: https://www.docker.com/products/docker-desktop/
2. Откройте командную строку в папке с программой
3. Выполните:
   ```
   docker-compose up -d
   ```

## Проблемы?

### GitHub Actions не запускается
- Убедитесь, что загрузили папку `.github` с файлом `workflows/build-windows.yml`
- Проверьте вкладку Actions — возможно нужно включить Actions для репозитория

### Сборка падает с ошибкой
- Откройте логи сборки и найдите красный текст с ошибкой
- Частая проблема: не все файлы загружены. Проверьте структуру репозитория.

- Артефакты доступны только 90 дней
